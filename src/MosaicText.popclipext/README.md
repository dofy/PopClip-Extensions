# Mosaic Text

Replace selected text with a configurable mosaic character. This is useful for
obscuring text in screenshots or previews.

## Usage

Select text, set the mosaic character in the extension settings, and choose
**Mosaic**. The transformed text is pasted while the original selection is
kept on the clipboard for recovery.

Because the original selection is intentionally copied to the clipboard, make
sure this behavior is appropriate before using the extension with sensitive
text.
