# Multi-Line to Array

Convert multi-line text into a JavaScript array. Options control empty lines,
quote style, trailing commas, brackets, trimming, and single-line output.

## Usage

Select one item per line, configure the output options, and choose the action.
The generated array is pasted into the current app. Quotes inside an item are
escaped using the selected quote style.
