# Open GitHub Repo

Open a GitHub repository from selected text in `AUTHOR/REPO` format.

## Usage

Select text such as `octocat/Hello-World` and choose the generated repository
action. The selection must match the `AUTHOR/REPO` format. You can optionally
configure your own GitHub username to show a second action that opens the same
repository name under your account.

The extension only constructs and opens `github.com` URLs; it does not call the
GitHub API or transmit the selection anywhere else.
