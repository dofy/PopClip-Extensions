# ray.so

Generate a shareable code image with [ray.so](https://ray.so), with options
for language, background, line numbers, theme, dark mode, and padding.

## Usage

Select source code, configure the image options, and choose **Generate Image**.
The extension opens ray.so in your current browser with the selected code and
options in the URL.

The selected code is encoded into the URL opened at ray.so. Review ray.so's
own privacy policy before using it with sensitive code.
