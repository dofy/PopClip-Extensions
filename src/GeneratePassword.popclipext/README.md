# Password Generator

Generate random passwords with configurable length, character classes,
custom symbols, ambiguity rules, repetition rules, and output mode.

## Usage

Choose **Password Generator** and configure the options in PopClip settings.
The length is clamped to 4–256 characters. You can enable lowercase,
uppercase, numbers, and symbols; replace the built-in symbol set; exclude
look-alike characters; and prevent adjacent duplicates.

After generating, choose whether PopClip should paste when possible, always
paste, always copy, or show the password only. Passwords are generated locally
using PopClip's secure random utility; no network service is used.
