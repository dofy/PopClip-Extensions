# Add to WordClip

Send the selected word to the WordClip app using its custom URL scheme.

## Usage

Select a word and choose **Add to WordClip**. WordClip must be installed and
registered to handle the `wordclip://` URL scheme. The selected text is URL
encoded before it is passed to WordClip.

The selected word is passed to WordClip through the URL scheme and is not sent
to any other service by this extension.
