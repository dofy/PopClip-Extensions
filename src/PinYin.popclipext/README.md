# PinYin

Convert Chinese characters to Pinyin or Zhuyin with selectable tone output.

## Usage

Select Chinese text and choose **PinYin** or **Zhuyin** from the submenu.
Configure tone marks, tone numbers, or no tones in the extension settings.

Use the **Output** setting to choose between **Show Result Only**, **Show and
Copy**, or **Copy Only**. The default is **Show and Copy**.
