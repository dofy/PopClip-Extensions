# DeepL Translator

Translate selected text with the DeepL Mac app or DeepL website.

## Usage

- Choose **DeepL App** to use the DeepL desktop app shortcut.
- Choose **DeepL Website** to open the translation in a browser.
- Configure the second language and optional custom keyboard shortcut in the
  extension settings.
- In website mode, hold Option to reverse the translation direction.

App mode uses DeepL's desktop shortcut, so the DeepL app must be installed.
Website mode opens a DeepL URL in the current browser; the selected text is
included in that URL and is therefore sent to DeepL. This extension does not
send the selection to any other service.

You can use DeepL's default `⌘C` twice shortcut or enable a custom modifier/key
combination in the settings.
