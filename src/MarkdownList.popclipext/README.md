# Markdown List

Convert selected multi-line text into a numbered or bulleted Markdown list.

## Usage

Select multiple lines and choose either **Numbered List** or **Bulleted List**
from the submenu. Each selected line receives the corresponding Markdown
prefix, and the result is pasted into the current app.
